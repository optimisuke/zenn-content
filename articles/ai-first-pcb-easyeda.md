# はじめに

ちょっと前から、AIに回路基板を作ってもらいたいなーと思っていました。

簡単な基板の設計自体は、10年以上前に仕事でやったことがあります。ただ、それから基板設計にはほとんど触れておらず、自分で製造会社へ発注したこともありませんでした。

久しぶりに調べてみると、設計ツールも発注の仕組みもそこそこ変わっていました。基板の製造だけでなく、部品調達や実装までオンラインで頼めます。さらに今は、部品選び、配置、配線、製造データの準備といっためんどくさいところをAIにかなり手伝ってもらえます。

普通のソフトウェアなら失敗しても直せばいいですが、基板は発注したあとに間違いに気づくと、それなりの勉強代がついてしまいます。ということで、作りたいものもそこまでないし、いつかやりたいなと思いつつ手を出せてませんでした。

そんなとき、イチケンさんの「AIに基板設計を頼んだら2時間で完成した」という動画を見ました。

https://youtu.be/qks8GUd94eM

この動画を見て、今ならそんなに時間かけなくてもいけるかもしれないと思い、実際に[EasyEDA](https://easyeda.com/)をAIに操作してもらいながら設計し、JLCPCBへ発注するところまでやってみました。

この記事を書いている時点では、基板はまだ届いてないので「無事に動いた記事」ではなく、基板設計から10年以上離れていた自分が、AIと一緒にはじめて発注するところまで進んだ記録です。

# 今回作ったもの

次の2種類を5枚ずつ発注しました。

1つ目は、USB-Cから給電すると自動で点滅するRGB LED基板です。マイコンは載せず、制御IC内蔵のRGB LEDを使います。電源を挿すだけで7色に点滅する、小さなエルチカ基板です。USB-C給電のエルチカ基板作りたいってCodexに相談したらRGB LEDを提案してくれました。

2つ目は、RP2040-Zero（Raspberry Pi Picoと同じマイコンが載った小型基板）の上に重ねる1キーマクロパッドです。マクロパッドと言っていいのかあやしいですが、Cherry MXスイッチを1個だけ載せました。

RGB LED基板は部品調達と実装もJLCPCBへ依頼し、マクロパッドは基板だけ作ってもらい、自分ではんだ付けする予定です。

# AIにはEasyEDAを直接操作してもらった

今回は、EasyEDA公式の[easyeda-api-skill](https://github.com/easyeda/easyeda-api-skill)を使いました。API GatewayとWebSocketブリッジを介してAIからEasyEDAを操作し、チャットしながら回路図の作成、部品配置、配線、GNDベタ、DRC（Design Rule Check：配線間隔や未接続などの製造ルールを確認するチェック）まで進めます。

ブラウザー側のJLCPCBでも、製造データのアップロード、部品の照合、金額の確認まではAIに手伝ってもらいました。一方で、住所、配送方法、支払いのようなところは自分で確認しました。

完成形から相談を始め、わからない用語はその場で聞けるのがかなりありがたかったです。ただし、AIの操作中に自分もEasyEDAを触ると部品の選択や配置が競合するので、保存を確認してから交代する方が良さそうです。

# USB-C RGB Blinker

USB-Cから5Vだけを受け取り、IC内蔵のRGB LEDを点滅させます。USB通信やUSB PDは使いません。

USB-CのCC1とCC2は、それぞれ5.1kΩでGNDへ落とします。これは電源を受け取る側であることを示すRd抵抗です。USB-Cコネクターを載せれば、そのまま5Vが出てくるわけではないんですね。ほかにLED保護用の抵抗と、電源安定化用のコンデンサーを載せました。

基板サイズは約11.176 × 21.844mmです。USB-CとLEDを縦に並べ、片面に部品を配置しました。シルクには、今回の記念として`ハジメテノエルチカ`と入れています。（もっといい言葉あった気はしますが。。。）

![](/images/ai-first-pcb-easyeda/pcb-layout.png)

配線までできると、急に「回路図」から「基板」になった感じがしてテンションが上がります。3D表示でも部品の向きを確認しました。

![](/images/ai-first-pcb-easyeda/pcb-3d-preview.png)

最終的にDRCは0件になりました。ただし、部品の高さやUSBケーブルを挿せるかといった物理的なことまでは保証してくれません。ここは届いた実物で確認します。

# RP2040-Zero 1キーマクロパッド

もう1枚は、RP2040-Zeroの上へ重ねる約20.6 × 25mmの基板です。Cherry MXスイッチをGPIO15とGNDの間へつなぎ、マイコンの内部プルアップを使ってキー入力を読み取ります。

最初はKailhのHot-swap Socketを使おうとしていました。はんだ付けせずスイッチを交換できるのは魅力的です。しかし、ソケットが基板裏へ大きく張り出し、そのすぐ下に置くRP2040-Zeroと干渉しそうでした。

今回は考えることを増やしたくなかったので、Cherry MX 5ピンを直接はんだ付けする構成へ変更しました。回路が正しそうでも、立体物として組み立てられるかは別問題でした。

# やってみてハマったところ

一番めんどくさかったのは部品の向きです。画面上の向き、完成品を使う向き、表から見た向きと裏から見た向きが混ざりました。

曖昧なまま「90度回して」と頼むと、人とAIで想像している完成形がズレます。配置を変えたあとに配線とGNDベタをやり直すことになり、なかなかめんどくさかったです。次からは「USBを上」「時計回り」のように言葉で向きを固定し、配置を確定してから配線します。いや、自分でやった方がはやいかもです。次は自分でやります。

GNDベタも、作ったあとに部品を動かすと再計算が必要でした。AIに「終わった」と言われても、3D表示や画面を見て違和感があれば信用しすぎないのが大事だと思います。

# 発注

RGB LED基板は、JLCPCBへ部品実装まで依頼しました。基板だけを発注する場合と違い、PCBAでは主に次の3種類のデータを使います。

- Gerber: 銅箔、レジスト、シルク、基板外形、穴などの製造データ
- BOM: 使用する部品とLCSC番号の一覧
- CPL: 各部品の実装座標、面、回転角

データ作成とアップロードもAIに手伝ってもらい、最後は3D配置画面でUSB-CやLEDの向きを自分でも確認しました。今回のざっくりした費用感は次のとおりです。

- 基板自体: 約1,000円
- 国際送料: 約3,000円
- RGB基板の部品調達とリフロー実装: 約6,000円

商品、送料、クーポンを合わせた小計は55.36ドルでした。実装は準備費など固定費に近い部分が大きく、枚数を増やしても総額は単純に倍にならないみたいです。そらそうか。

# AIに任せてみてどうだったか

10年以上のブランクがある状態から、2種類をDRC 0件にして発注まで進められたのは、かなりびっくりな体験でした。製造データや部品表の作り方を一つずつ調べていたら、途中でめんどくさくなっていたと思います。

一方で、AIに丸投げすれば安心という感覚はまだまだないです。向きのズレや物理的な干渉までは残るので、発注直前は3D表示等で自分でも確認する必要があります。

それでも、設計から部品選び、製造データの準備、発注画面の確認までAIと一緒に進められ、自分で基板を発注するハードルはかなり下がったという感覚です。

届いたら、RGB LEDが本当に光るか、USB-Cやマクロパッドの部品が干渉しないかを確認します。ちゃんと光る基板が届きますように。
