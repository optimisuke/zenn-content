# はじめに

ちょっと前から、AIに回路基板を作ってもらいたいなーと思っていました。

簡単な基板の設計自体は、10年以上前に仕事でやったことがあります。ただ、それから基板設計にはほとんど触れておらず、自分で製造会社へ発注したこともありませんでした。

久しぶりに調べてみると、設計ツールも発注の仕組みもそこそこ変わっていました。基板の製造だけでなく、部品調達や実装までオンラインで頼めます。さらに今は、部品選び、配置、配線、製造データの準備といっためんどくさいところをAIにかなり手伝ってもらえます。

普通のソフトウェアなら失敗しても直せばいいですが、基板は発注したあとに間違いに気づくと、それなりの勉強代がついてしまいます。ということで、作りたいものもそこまでないし、いつかやりたいなと思いつつ手を出せてませんでした。

そんなときに、イチケンさんの「AIに基板設計を頼んだら2時間で完成した」という動画を見ました。

https://youtu.be/qks8GUd94eM

この動画を見て、今ならそんなに時間かけなくてもいけるかもしれないと思い、実際に[EasyEDA](https://easyeda.com/)をAIに操作してもらいながら設計し、JLCPCBへ発注するところまでやってみました。

この記事を書いている時点では、基板はまだ届いてないので「無事に動いた記事」ではなく、基板設計から10年以上離れていた自分が、AIと一緒にはじめて発注するところまで進んだ記録です。

# 今回作ったもの

いきなり複雑な回路は怖かったので、次の2種類を作りました。

1つ目は、USB-Cから給電すると自動で点滅するRGB LED基板です。マイコンは載せず、制御IC内蔵のRGB LEDを使います。電源を挿すだけで7色に点滅する、小さなエルチカ基板です。USB-C給電のエルチカ基板作りたいってCodexに相談したらRGB LEDを提案してくれました。

2つ目は、 RP2040-Zero (Raspberry Pi Picoのマイコンのった基板) の上に重ねる1キーマクロパッドです。（マクロパッドと言っていいのかあやしいですが）Cherry MXスイッチを1個だけ載せ、GPIO15とGNDの間をスイッチでつなぐだけの構成にしました。

どちらも5枚ずつ発注しました。RGB LED基板は部品調達と実装もJLCPCBへ依頼し、マクロパッドは基板だけ作ってもらい、自分ではんだ付けする予定です。

# AIにはEasyEDAを直接操作してもらった

今回は、AIからEasyEDAを操作するAPI Gatewayとブリッジを使いました。AIとチャットしながら、回路図の作成、部品配置、配線、GNDベタ、DRC（Design Rule Check：配線間隔や未接続などの製造ルールを確認するチェック）まで進めます。

ブラウザー側のJLCPCBでも、製造データのアップロード、部品の照合、金額の確認まではAIに手伝ってもらいました。一方で、住所、配送方法、支払いのようなところは自分で確認しました。

「USB-Cで給電して、自動で点滅する小さいRGB基板を作りたい」のように、完成形から相談を始められるのはかなりありがたかったです。わからない用語が出るたびに、その場で聞けるのも助かりました。

ただし、AIが操作している途中に自分もEasyEDAを触ると、選択中の部品や配置が競合します。AIが動かした直後に自分が戻したり、その逆が起きたりしました。操作担当を交代するときは、保存が終わったことを確認してから触る方が良さそうです。

# USB-C RGB Blinker

## 回路

USB-Cから5Vだけを受け取り、IC内蔵のRGB LEDを点滅させます。USB通信やUSB PDは使いません。

主な部品は次のとおりです。

| 部品              | 用途                 | LCSC番号 |
| ----------------- | -------------------- | -------- |
| USB-Cコネクター   | 電源入力             | C165948  |
| XL-5050RGBC-MS    | 自動点滅RGB LED      | C2843784 |
| 5.1kΩ抵抗 × 2     | USB-CのCC1/CC2用     | C23186   |
| 120Ω抵抗          | LED側の保護          | C22787   |
| 100nFコンデンサー | 電源のデカップリング | C14663   |

USB-CのCC1とCC2は、それぞれ5.1kΩでGNDへ落とします。これは、こちらが電源を受け取る側であることを示すRd抵抗です。今回初めて知りました。USB-Cコネクターを載せれば、そのまま5Vが出てくるわけではないんですね。

100nFのコンデンサーは、LEDが点滅するときの急な電流変化や高周波ノイズを吸収するため、LEDの電源ピンの近くへ置きました。

## PCBレイアウト

基板サイズは約11.176 × 21.844mmです。USB-CとLEDを縦に並べ、片面に部品を配置しました。シルクには、今回の記念として`ハジメテノエルチカ`と入れています。

![](/images/ai-first-pcb-easyeda/pcb-layout.png)

配線までできると、急に「回路図」から「基板」になった感じがしてテンションが上がります。

EasyEDAの3D表示でも確認しました。USB-Cコネクターの差し込み口が基板端から少し出ていますが、これはケーブルを挿しやすくするための配置です。固定パッドやシールド足は基板内に収めています。

![](/images/ai-first-pcb-easyeda/pcb-3d-preview.png)

最終的にDRCは0件になりました。DRCは配線間隔、未接続、基板端との距離、穴径などの製造ルールを機械的に確認するものです。

ただし、DRCが0件でも本当に動くとは限りません。部品の高さ、USBケーブルを挿せるか、コネクターへ力が掛かったときに大丈夫か、といった物理的なことまでは保証してくれません。このあたりは3D表示と、届いた実物で確認する必要があります。

# RP2040-Zero 1キーマクロパッド

もう1枚は、RP2040-Zeroの上へ重ねる1キーマクロパッドです。基板サイズは約20.600 × 25.000mmで、左右各9ピンの2.54mmピッチでRP2040-Zeroと接続します。

回路はかなり単純で、Cherry MXスイッチをGPIO15とGNDの間へ接続します。ファームウェア側で内部プルアップを有効にし、通常時をHIGH、キーを押したときをLOWとして読み取る想定です。

最初はKailhのHot-swap Socketを使おうとしていました。はんだ付けせずスイッチを交換できるのは魅力的です。しかし、ソケットが基板裏へ大きく張り出し、そのすぐ下に置くRP2040-Zeroと干渉しそうでした。

スペーサーを高くすれば避けられるかもしれませんが、久しぶりの基板設計で考えることを増やしたくなかったので、今回はCherry MX 5ピンを直接はんだ付けする構成へ変更しました。

回路として正しそうでも、立体物として組み立てられるかは別問題でした。PCB設計は回路と配線だけではなく、部品の厚みやケーブルを挿す空間まで考える必要があるということを、この基板で実感しました。

# 一番めんどくさかったのは「向き」

今回かなり混乱したのが、部品の向きです。

- EasyEDAの画面上で見た向き
- 完成した基板を使うときの向き
- USBコネクターを手前にしたときの向き
- 表面から見た向きと裏面から見た向き

このあたりを曖昧なまま「90度回して」と頼むと、人とAIで想像している完成形がズレます。配置を変えたあとに配線とGNDベタをやり直すことになり、なかなかつらかったです。

次からは、配線を始める前に次のように決めます。

1. 完成品を使う向きの簡単な絵を作る
2. 「USBを上」のように言葉でも定義する
3. 回転は時計回り・反時計回りまで指定する
4. 部品の中心座標を数値で確認する
5. 配置を確定してから配線する

特にCherry MXスイッチは、シルクの`SW1`やフットプリント外形ではなく、中央軸の穴を基板外形の中心へ合わせる必要がありました。画面を見た感じだけでなく、座標で確認するのが大事でした。

# GNDベタも作って終わりではなかった

GNDは細い配線だけで数珠つなぎにせず、空いている領域にGNDポリゴンを配置しました。2層基板の両面をGNDベタにしてビアで接続すると、GNDへ戻る経路を短くでき、配線もしやすくなります。

ここでも一度ハマりました。GNDベタを作ったあとに部品を移動したところ、古い形状が残り、不自然な見た目になりました。部品配置や基板外形を変更したら、GNDベタも再計算する必要があります。

AIに「移動したから終わり」と言われても、3D表示や画面を見て違和感があれば聞き直すのは大事だと思います。

# PCBA発注で初めて知ったこと

RGB LED基板は、JLCPCBへ部品実装まで依頼しました。基板だけを発注する場合と違い、PCBAでは主に次の3種類のデータを使います。

- Gerber: 銅箔、レジスト、シルク、基板外形、穴などの製造データ
- BOM: 使用する部品とLCSC番号の一覧
- CPL: 各部品の実装座標、面、回転角

アップロード後の3D配置画面では、特にUSB-Cと極性のあるLEDの向きを確認しました。

また、今回使った自動点滅RGB LEDはStandard PCBA対象の部品だったため、Economic PCBAではなくStandard PCBAになりました。

小さい基板は、そのままだと自動実装機へ流しにくいため、JLCPCB側で作業用のパネルとレールが追加されます。今回は実装後にレールを切り離して個片で納品するデパネリングも指定しました。このあたりは、最初に見た見積もりから費用と日数が増えるポイントでした。

# 費用感

今回のざっくりした体感は次のとおりです。

- 基板自体: 約1,000円
- 国際送料: 約3,000円
- RGB基板の部品調達とリフロー実装: 約6,000円

カート確認時は、商品が56.36ドル、送料が9ドル、クーポンがマイナス10ドルで、小計55.36ドルでした。為替や支払い条件で日本円の請求額は変わります。

意外だったのは、実装費が単純に枚数へ比例しないことです。ステンシル、部品フィーダーの設定、梱包など、固定費に近い費用の割合が大きく、5枚を10枚にしても総額が2倍になるわけではありませんでした。次回は5枚だけで決めず、10枚や20枚の見積もりも比較してみたいです。

# AIに任せてみてどうだったか

10年以上のブランクがある状態から、2種類をDRC 0件にして発注まで進められたのは、かなりすごい体験でした。昔の作業を細かく覚えているわけではないので厳密な比較はできませんが、少なくとも自分で製造会社を探し、製造データや部品表の作り方を一つずつ調べていたら、途中でめんどくさくなっていたと思います。

今回は、わからないことを作業中にAIへ質問し、そのままEasyEDAも操作してもらえました。設計から部品選び、製造データの準備、発注画面の確認までがつながっていて、以前よりも自分で基板を発注するハードルはかなり下がっているという感覚です。

一方で、AIに丸投げすれば安心という感覚ではありませんでした。

向きの指示がズレる、GNDベタの再計算が必要になる、API Gatewayの接続が切れる、部品の3D形状だけでは実物の干渉を断言できない、といったことは普通に起きます。特に発注直前は、AIの返事よりも、Gerber Viewerや3D表示に出ているものを正として自分でも確認する必要があります。

それでも、10年以上前の知識をきちんと思い出してから始めようとしていたら、たぶんまだ何も発注していなかったと思います。先に作り始めて、CC抵抗、デカップリングコンデンサー、GNDベタ、DRC、BOM、CPLを一つずつ確認していく進め方は、自分にはしっくりきています。

# 到着したら確認すること

まだ届いていないため、少なくとも次を確認する予定です。

- USB-C接続だけでRGB LEDが自動点滅するか
- USB-Cコネクターの機械的な強度
- 白い基板上でシルクが読みやすいか
- RP2040-Zeroと左右のピンが無理なく接続できるか
- Cherry MXのピンやはんだ面がRP2040-Zeroへ干渉しないか
- キー入力をGPIO15の内部プルアップで読み取れるか

問題なく動いたら、届いた基板の写真と動作確認も追記したいと思います。間違った物体が届くのか、ちゃんと光る基板が届くのか、今は楽しみ半分、不安半分です。
